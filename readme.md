
# README: Программа "Алгоритмы растеризации"

## Описание
Эта программа демонстрирует работу основных растровых алгоритмов рисования линий и окружностей:  
- **Алгоритм Брезенхема для линий**  
- **Алгоритм Брезенхема для окружностей**  
- **Алгоритм ЦДА (Цифрового Дифференциального Анализатора)**  
- **Пошаговый алгоритм для линий**  

Пользователь может выбрать алгоритм из списка, указать начальную и конечную точки (или центр и радиус для окружности) на холсте, а затем наблюдать результат работы алгоритма. Программа также ведёт журнал операций, отображающий параметры линии/окружности, использованный алгоритм и время работы алгоритма.

## Как пользоваться
1. Выберите алгоритм из выпадающего списка в левой части окна.  
2. Для линии:
   - Щёлкните левой кнопкой мыши на холсте, чтобы выбрать первую точку.
   - Щёлкните ещё раз, чтобы выбрать вторую точку. Линия будет отрисована.  
3. Для окружности:
   - Щёлкните, чтобы выбрать центр окружности.  
   - Щёлкните в другом месте, чтобы указать радиус. Окружность будет отрисована.  
4. В правой части интерфейса отображается **журнал отрисовки**, включающий информацию о нарисованных фигурах.  
5. Для очистки холста нажмите кнопку **"Очистить"**. Это удалит всё с холста и добавит разделяющую линию в журнал.


# Алгоритмы
### 1. Алгоритм Брезенхема (линия)
**Описание**:  
Растеризует прямую линию между двумя точками на основе целочисленных вычислений. Минимизирует отклонения от идеальной линии с помощью пошагового вычисления ошибки.

**Плюсы**:
- Высокая производительность благодаря целочисленным вычислениям.
- Простая реализация.
- Высокая точность для прямых линий.

**Минусы**:
- Работает только для прямых линий.
- Может потребовать модификации для поддержки антиалиасинга.

**Сложность**:
 - O(max(Δx,Δy))
---

### 2. Алгоритм Брезенхема (окружность)
**Описание**:  
Растеризует окружность с использованием её симметрии. Рассчитывает только одну восьмую часть окружности и зеркально отражает точки.

**Плюсы**:
- Высокая производительность благодаря симметрии.
- Точность, ограниченная только дискретностью экрана.
- Целочисленные вычисления.

**Минусы**:
- Применим только к окружностям.
- Сложнее реализуется для эллипсов или произвольных кривых.

**Сложность**
- O(r), где r — радиус.
---

### 3. Алгоритм ЦДА (Цифровой Дифференциальный Анализатор)
**Описание**:  
Генерирует линии, используя дробные приращения координат на основе угла наклона линии.

**Плюсы**:
- Простота и понятность алгоритма.
- Подходит для прямых линий любой длины.

**Минусы**:
- Меньшая точность из-за ошибок округления.
- Требует операций с плавающей точкой, что может быть медленным на ограниченных системах.

**Сложность**:
 - O(max(Δx,Δy))
---

### 4. Пошаговый алгоритм
**Описание**:  
Растеризует линию, рассчитывая координаты каждой точки поочерёдно на основе пропорций между координатами ( x) и ( y ).

**Плюсы**:
- Простой для понимания и реализации.

**Минусы**:
- Низкая точность из-за использования дробных значений.
- Более медленный по сравнению с другими алгоритмами.
- Создаёт прерывистые линии при большом уклоне.

**Сложность**:
 - O(max(Δx,Δy))
